# Projeto-Auto-Peças
Site Completo 

CLAUDE DESIGN 
Quero que você atue como um UX/UI Designer sênior especializado em sites institucionais, e-commerce, automotive e experiências digitais modernas.

Preciso criar o DESIGN COMPLETO de um novo site para:

PASSINI DISTRIBUIDORA DE AUTO PEÇAS

A imagem da fachada/logo da empresa está anexada. Use essa imagem como referência visual obrigatória para desenvolver a identidade do projeto.

==================================================
OBJETIVO
==================================================

Criar um layout completo, moderno, profissional e premium para uma grande distribuidora de autopeças.

O site deve transmitir:

- confiança
- tradição
- experiência
- grande variedade de produtos
- atendimento especializado
- tecnologia
- eficiência
- proximidade com oficinas e profissionais
- facilidade para encontrar a peça correta

O conceito visual deve ser:

EMPRESA TRADICIONAL + TECNOLOGIA MODERNA.

Não quero que o resultado pareça um template genérico de autopeças.

Também não quero um visual excessivamente futurista.

Quero algo que pareça uma empresa grande, consolidada e profissional que está modernizando sua experiência digital.
